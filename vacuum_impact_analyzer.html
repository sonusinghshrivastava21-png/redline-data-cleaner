How events are found
  1. Vacuum is smoothed with a rolling median to remove sensor noise.
  2. An event is a rise of at least the minimum, within the set time.
  3. The event starts at the last moment vacuum was still near its low point. "Before" values are the average of the baseline period.
  4. Load and coal are watched for the set time. Max drop / max increase are the extremes in that period; "settled" values average its last part.
  5. The next event is only looked for after the watch ends, so one upset is counted once.
